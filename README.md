# ConcreteCore／砼核

**探激／C-EXCITE（C-EXCITE-STUDIO）｜工作稿v0.2｜繁體中文**

混凝土怎樣不只替故事承重，而成為值得凝視、理解與創作的對象？本書以材料中心的閱讀框架，連接造物、共同生活、個體投入、城市記憶、遺跡、精神象徵與未來想像。

砼核的基線是：混凝土在作品中**可辨識、在美學上不可替代，並成為主要審美對象之一**。這不是巨大、粗糙、無人或複雜情緒的資格清單；七簇也是目前採用的組織方式，而不是永久分類。
